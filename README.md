## Legenda

| Tag | Significado |
|:--|:--|
| ✨ **Adicionado** | Novos sistemas, armas, mapas ou recursos |
| 🔧 **Alterado** | Ajustes de balanceamento e mudanças em sistemas existentes |
| 🐛 **Corrigido** | Correções de bugs |
| 🗑️ **Removido** | Itens ou sistemas retirados do jogo |

## Versionamento

As versões seguem o formato `MAIOR.MENOR.CORREÇÃO`:

- **MAIOR**: grandes atualizações ou temporadas.
- **MENOR**: novos conteúdos e sistemas.
- **CORREÇÃO**: correções e ajustes rápidos.
